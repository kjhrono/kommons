# HERALD

A herald walks the road ahead of every banner and reports what the road
will bear. HERALD is that walker as a game — and the kommons package's
example consumer: a complete minimal kjhrono game on the shared shell
(splash, top bar, settings with the reference OAuth wiring, lobby wizard),
in ~200 lines with zero copied shell code.

Use it as the starting template for a new game, and read the package's
[COMMONS.md](../../COMMONS.md) for the full adoption recipe.
